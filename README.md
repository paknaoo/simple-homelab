# Simple Homelab
## Overview

This repository documents a small and simple homelab built for learning and experimentation.
The main goal of this lab is to practice working with a firewall and virtualization environment using pfSense and VMware Workstation Pro.

The lab environment also provides a place to learn the basics of Linux servers, networking, and basic security testing tools.

## Goals of the Lab

The homelab was created to practice and learn:

Firewall configuration and networking with pfSense

Virtual machine management using VMware Workstation Pro

Basic Linux server administration on Ubuntu Server

Network scanning and discovery using Kali Linux

Traffic analysis with tools such as Wireshark

Network scanning with Nmap

## Lab Architecture

The lab is intentionally simple and contains only a few virtual machines connected to a single LAN network.

## Virtual Machines

pfSense – acts as the firewall and gateway

Ubuntu Server – used to host and test basic server services

Kali Linux – used for network analysis and security testing

All machines are connected to the same LAN network, with pfSense acting as the firewall between the internal network and the internet.

## Purpose

This project is intended purely for learning and educational purposes.
The lab environment allows safe experimentation with networking, firewall rules, server configuration, and security tools.
